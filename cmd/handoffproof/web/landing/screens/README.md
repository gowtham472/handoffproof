# Product screenshots

These images show the HandoffProof interface, captured from a read-only local
review of this repository. Readiness and Evidence display the existing recorded
demo rehearsal data, including controller evidence IDs. Connections shows the
Settings overview with isolated integration storage. These are product screenshots,
not live measurements or illustrations. No new drill ran to create these images.

Capture the page's content viewport with a screenshot clip whose width is
`document.documentElement.clientWidth` and height is `window.innerHeight`.
This excludes the browser's scrollbar gutter without changing application styles
or disabling scrolling. Current captures are 2545 x 1440 pixels, rendered at
twice the usual UI scale in a temporary read-only capture view. The production
application has no capture scaling or scrollbar-style changes. The hero loads
the original high-resolution capture eagerly at high fetch priority.
