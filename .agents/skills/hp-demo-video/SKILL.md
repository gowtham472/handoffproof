# Task: 3-minute demo video (only work built during the event)

0:00 Problem: the site looks fine, the developer is gone, confirmations silently stop.
0:25 Baseline: register, book, email arrives, acceptance passes.
0:55 Drill: withdraw the token. Booking shows success, email assertion fails.
1:30 Evidence view: failed step, log excerpt, source reference, the Meta model's diagnosis.
2:00 Second drill, with the model reading messy docs ("ask Ravi").
2:25 Repair and rerun with unchanged acceptance hashes: green.
2:45 Results table, including honest misses.

## Rules
- Show the Meta model doing real work on screen. Show no secrets.
- Record a safe take the day before the deadline, then improve if time allows.
- Keep under 3:00. Captions help; keep text readable.
