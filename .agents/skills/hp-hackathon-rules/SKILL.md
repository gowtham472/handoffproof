# Hackathon rules and priorities (constraint)

## Scoring (as reported from the official rules; verify on the submit page)
impact 30%, creative use of Meta AI tooling 25%, demo including video 25%, technical depth 20%.

## Rules
- Only new work, started during the event. Keep a "Built during the event" section in the README.
- Public repository at submission. All contributors listed. Indie track only.
- Must genuinely use Meta Model API or open-weight models; the runtime agent must call it.
- 3-minute demo video showing only work built during the event.
- Deadline: Nov 4, 9:00 PM ET (Nov 5, 6:30 AM IST). Aim to submit at least 6 hours early.

## Priority order when time runs short
1. Working end-to-end demo with the Meta model doing real work
2. The 3-minute video
3. One honest results table
4. Extra drills, UI polish, second app

## Do not
Claim results that were not measured. Label targets as targets.
